Bulk athlete photos

Exports one record per athlete from this browser's combined athlete list. The local PowerShell tool searches Wikimedia Commons only. Search results are candidates, not identity matches: review each candidate before approving it. The tool downloads only approved files with reusable CC0, public-domain, CC BY, or CC BY-SA licenses and preserves attribution details. Resized CC BY-SA images retain that license. A copyright license does not guarantee identity, portrait/privacy rights, or permission to publish student photos; check those separately.

Workflow: export the catalog, move the downloaded athlete-photo-catalog.json into the project folder, and open PowerShell there. Run powershell -NoProfile -ExecutionPolicy Bypass -File .\bulk-athlete-photos.ps1 -Action Search; review athlete-photo-candidates.csv and set Decision to approve only when the image is clearly the correct athlete; run the same command with -Action Apply; then import athlete-photo-manifest.json. Images and reports are saved under images\athletes and the project folder. No API key or paid service is required; internet access is required. Existing photos are skipped on reruns, and no roster entries are created or changed.
